## Other sources and limitations

- `day-one-logo.png`: supplied logo, unchanged.
- `Evaluation Comparison/ProblemSolutionText.md`: design-team problem/solution summary. Used to describe refinements, not as additional participant evidence.
- `Evaluation Comparison/Evolution.tsx`: supplied Remotion reference (8 seconds, 1920×1080, 30 fps); moving problem/solution text and a screenshot wipe. Inspected as reference only; not executed or ported into V0.1.
- No standalone final-screen archive was supplied. Scene 08 uses the explicitly named refined comparison images.
- No one-to-one Low-Fi mapping is established for every feature. The map/journey/AR sketch is a multi-concept sheet; no invented per-screen crop or pairing.
- The PDF reports approximate 30–35 minute sessions, while some appendix transcripts extend beyond this. The website attributes the duration to the Method section.
- No task completion rates, error rates, satisfaction scores, or post-refinement testing results are claimed.
